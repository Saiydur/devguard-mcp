# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text is at that link and applies in all project spaces
(issues, pull requests, discussions, and any channel where the project is represented).

In short:

- **Be respectful and constructive.** Welcome newcomers; assume good faith; give and accept
  feedback graciously.
- **No harassment, discrimination or personal attacks**, and no publishing of others' private
  information.
- **Victims of these attacks are welcome here.** Many contributors arrive after being compromised;
  treat reports with empathy and without blame.
- **Security work has extra rules.** Do not share live malware or exploits in project spaces; see
  [SECURITY.md](SECURITY.md#handling-malware-samples). Do not use this project to target, scan or
  harass systems you do not own or have permission to assess.

## Enforcement

Report unacceptable behaviour privately to the maintainers (use GitHub's report-content tools or
the contact in the repository profile). Maintainers will review every report, respect the
reporter's privacy, and may remove content, warn, or ban contributors as the Covenant describes.
